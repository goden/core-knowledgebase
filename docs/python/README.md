## 講義模板
每個單元包含：學習目標 → 概念說明 → 範例程式 → 常見錯誤 → 課堂練習 → 單元考題 → 重點整理；答案與參考解答獨立成 `unit-XX-answers.md`。

## 檔案命名
- 講義：`unit-XX-<主題英文>.md`
- 答案：`unit-XX-answers.md`
- 範例與解答程式：`examples/unitXX_<名稱>.py`
