# 單元 2：運算子與條件判斷

## 學習目標
- 能使用算術、比較、邏輯運算子組成運算式。
- 能分辨 `=`（指派）與 `==`（比較）。
- 能以 `if` / `elif` / `else` 撰寫多分支的條件判斷。

## 一、概念說明
- **運算子**是對資料做運算的符號，就像計算機上的按鍵。
- **條件判斷**讓程式能「如果……就……否則……」，像是路口的紅綠燈，依狀況走不同的路。

### 算術運算子
以 `7` 與 `3` 為例：

| 運算子 | 說明 | 範例 | 結果 |
|---|---|---|---|
| `+` | 加 | `7 + 3` | `10` |
| `-` | 減 | `7 - 3` | `4` |
| `*` | 乘 | `7 * 3` | `21` |
| `/` | 除（結果一定是 `float`） | `7 / 3` | `2.3333333333333335` |
| `//` | 整數除法（無條件捨去） | `7 // 3` | `2` |
| `%` | 取餘數 | `7 % 3` | `1` |
| `**` | 次方 | `7 ** 3` | `343` |

簡寫的指派運算子：`x += 1` 等同於 `x = x + 1`，另有 `-=`、`*=`、`/=` 等。

### 比較運算子
結果一律是 `bool`（`True` 或 `False`）。

| 運算子 | 說明 |
|---|---|
| `==` | 等於 |
| `!=` | 不等於 |
| `>`、`<` | 大於、小於 |
| `>=`、`<=` | 大於等於、小於等於 |

> 注意：`=` 是「指派」，`==` 才是「比較是否相等」。

### 邏輯運算子
| 運算子 | 說明 | 範例 | 結果 |
|---|---|---|---|
| `and` | 兩邊都為真才為真 | `True and False` | `False` |
| `or` | 任一邊為真即為真 | `True or False` | `True` |
| `not` | 反轉真假 | `not True` | `False` |

小技巧：Python 支援連續比較，`60 <= score < 80` 等同於 `score >= 60 and score < 80`。

### `if` / `elif` / `else`
```python
if 條件一:
    條件一成立時執行
elif 條件二:
    條件一不成立、條件二成立時執行
else:
    以上皆不成立時執行
```
規則：
- 條件後面要加冒號 `:`。
- 區塊內容要**縮排**（慣例為 4 個空白），縮排就是區塊的範圍。
- 由上而下判斷，只會執行**第一個**成立的區塊。

## 二、範例程式

### 範例 1：各種運算子
程式：[examples/unit02_operators.py](examples/unit02_operators.py)

```python
a = 17
b = 5

print(a + b, a - b, a * b)    # 算術運算
print(a / b)                  # 一般除法
print(a // b, a % b)          # 整數除法與餘數
print(a ** 2)                 # 次方
print(a > b, a == b, a != b)  # 比較運算
print(a > 10 and b > 10)      # 邏輯運算：and
print(not (a > 10))           # 邏輯運算：not
```

預期輸出：
```
22 12 85
3.4
3 2
289
True False True
False
False
```

### 範例 2：成績等級判斷
程式：[examples/unit02_grade.py](examples/unit02_grade.py)

```python
score = int(input("請輸入分數："))

# 由高到低依序判斷，條件順序很重要
if score >= 90:
    print("等級：A")
elif score >= 80:
    print("等級：B")
elif score >= 60:
    print("等級：C")
else:
    print("等級：不及格")
```

| 輸入 | 預期輸出 |
|---|---|
| `95` | `等級：A` |
| `85` | `等級：B` |
| `59` | `等級：不及格` |

想一想：若把 `score >= 60` 放在最前面，輸入 `95` 會得到什麼？（`等級：C`，因為只執行第一個成立的區塊。）

## 三、常見錯誤
| 錯誤 | 原因 | 修正 |
|---|---|---|
| `SyntaxError: invalid syntax` | 條件後忘了冒號，或把 `==` 寫成 `=` | 補上 `:`，比較用 `==` |
| `IndentationError` | 區塊內沒有縮排，或縮排不一致 | 統一使用 4 個空白 |
| `TypeError: '>' not supported between instances of 'str' and 'int'` | 直接拿 `input()` 的字串與數字比較 | 先用 `int()` 或 `float()` 轉換 |
| `0.1 + 0.2 == 0.3` 得到 `False` | 浮點數有精度誤差 | 比較小數時避免直接用 `==` |

## 四、課堂練習
1. 讓使用者輸入一個整數，判斷它是奇數還是偶數並印出結果。
   - 提示：用 `%` 取除以 2 的餘數。
2. 購物折扣：讓使用者輸入購物金額，滿 3000 打 8 折，滿 1000 打 9 折，否則原價，印出應付金額（以 `round()` 取到小數第 1 位）。
   - 提示：用 `elif`，條件由金額大的開始判斷。

## 五、單元考題
1. **選擇題**：`7 // 2` 與 `7 % 2` 的結果分別是？
   - A. `3.5` 與 `1`　B. `3` 與 `1`　C. `3` 與 `3.5`　D. `4` 與 `1`
2. **選擇題**：下列哪一個運算式的結果為 `True`？
   - A. `(5 > 3) and (2 > 4)`　B. `not (3 > 5)`　C. `3 == 3.5`　D. `"a" != "a"`
3. **填空題**：判斷變數 `x` 是否為 5 的倍數，應寫 `if x ____ 5 == 0:`；比較兩個值是否相等應使用 ______，而不是 `=`。
4. **程式題**：讓使用者輸入年份，判斷是否為閏年。規則：能被 4 整除且不能被 100 整除，或能被 400 整除，即為閏年。輸出「閏年」或「平年」。

## 六、重點整理
- 算術運算子：`+ - * / // % **`，其中 `/` 一律回傳 `float`。
- 比較運算子回傳 `bool`；`=` 是指派，`==` 才是比較。
- 邏輯運算子：`and`、`or`、`not`，可用來組合多個條件。
- `if` / `elif` / `else` 由上而下判斷，只執行第一個成立的區塊，區塊以縮排表示。
