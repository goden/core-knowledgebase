# Agent instructions

This repository is the agent's knowledge base.

- Entries live in `knowledge/`, one topic per Markdown file, created from `knowledge/_TEMPLATE.md`.
- To answer questions, search `knowledge/` first (titles, tags, summaries) and cite the file used.
- To remember something new, add or update an entry and set `updated` to today's date.
- Keep entries short, factual, and free of secrets.
